### APIs Utilizadas

* **1. API de Trivia**
  * Preguntas de trivia generales.
  * Enlace: [https://opentdb.com/api.php?amount=10](https://opentdb.com/api.php?amount=10)

* **2. API de Personajes**
  * Consulta de personajes de la serie.
  * Enlace: [https://rickandmortyapi.com/api/character](https://rickandmortyapi.com/api/character)

* **3. API de Pokémon (Species)**
  * Obtener especies de Pokémon.
  * Enlace: [https://pokeapi.co/api/v2/pokemon-species/aegislash](https://pokeapi.co/api/v2/pokemon-species/aegislash)
